# Video playlists (#370): device checks

Real Apple TV, Siri Remote unless noted. One line per check.

## Sidebar
- [ ] Each server with video playlists shows its own Playlists row.
- [ ] The Settings toggle hides and restores the Playlists rows.
- [ ] A server with every library hidden still shows its Playlists row correctly.
- [ ] Servers mixed into one "Libraries" section list their Playlists rows in the right place.

## Playlists grid and playlist page
- [ ] Opening a playlist page puts focus on Play.
- [ ] Up from the grid reaches Play and Shuffle.
- [ ] Right from Shuffle moves focus as expected.
- [ ] Menu closes the page from the header.
- [ ] Menu closes the page from the grid.

## Play
- [ ] Play on a partly watched playlist shows the Continue popup, and both choices start the right entry.
- [ ] Shuffle starts a shuffled order.
- [ ] Play from Here on a duplicate entry starts that copy.

## Playing through the queue
- [ ] Movie, then episode, then movie plays in order.
- [ ] The last item ends playback and closes the player.
- [ ] The Up Next card reads correctly when the next entry is a movie.
- [ ] Menu during the countdown cancels it.
- [ ] Play Now the instant the card appears starts the next entry once.
- [ ] A Plex entry that 404s shows the error and does not strand the player.
- [ ] The in-player Playlist pill shows; the pane marks the right copy of a duplicate entry.
- [ ] Selecting a row in the Playlist pane jumps to that entry.

## Editing
- [ ] Add to Playlist, New Playlist... opens the keyboard and creates the playlist.
- [ ] Remove updates at once, and rolls back on a server error.
- [ ] Rename updates the title.
- [ ] Delete asks to confirm, then removes the playlist.
- [ ] Music's New Playlist... from the "..." menu: the keyboard appears after the system menu closes.
- [ ] A folder video can be added to a playlist.

## Move
- [ ] Arrow clicks move the entry in all four directions.
- [ ] Swipes move the entry in all four directions.
- [ ] Down on a long playlist moves to an off-screen target cell.
- [ ] Holding Up or Down past 1.5 s keeps moving and does not lose focus.
- [ ] Select drops the entry without opening the tile.
- [ ] Menu cancels the move and restores the order.
- [ ] A refresh during a move does not corrupt the order.
- [ ] Settings > Sidebar library reorder works as before.
- [ ] iPhone Remote (swipes only) can move and drop an entry.
